# 奶蛙街头 · MILKFROG FIGHT CLUB

经典奶蛙表情包的横版街机格斗小游戏。奶油色小报页面、午后老街擂台、平视对手的圆眼奶蛙。纯 HTML / CSS / JavaScript / Canvas，运行时没有框架、CDN 或后端依赖，可以部署在 GitHub Pages 的仓库子路径。

## 立即运行

安装 Node.js 20 或更新版本后，在项目目录运行：

```sh
npm run dev
```

打开 `http://localhost:4173`。无需 `npm install`。页面使用 ES modules，请通过本地 HTTP 服务打开。

## 已实现

- 人机对战：三档难度，三局两胜，每局 90 秒。
- 同屏双人：两套键盘按键，也支持两只标准手柄。
- 自由练习：无限奶气、无限时间、连招后自动回血，可切换格挡木桩。
- 六位选手：奶蛙（均衡 / 奶气波）、奶绿（速度 / 疾风突进）、奶红（重击 / 红温震地）、奶紫（控场 / 减速）、奶粉（奶心弹命中回血、失衡）、奶蓝（冰晶短冻、减速）。
- 两张可在主页选择的地图：晴日老街、雨巷街口。雨天地面有湿润反光，叠加实时雨滴与涟漪；主页保留选蛙区和操作速查。
- 23 种招式：三连拳、蹲拳、扫堂腿、空中拳、飞燕踢、升龙、抱摔、旋风腿、冲肩拳、滑铲、多种奶气技能，以及专属必杀、百裂奶拳、九天升龙、天降奶雨和六段连携终式。
- 战斗角色缩至此前的 70%，站立高度约占战场高度 20%；双击方向冲刺、持续 2.15 倍奔跑、高 / 中 / 低 / 空中压制 / 对空 / 投技判定、站防与蹲防、命中取消、气功相消、打击停顿与击退。
- 3840 单位宽的街区、向上延伸的活动空间与多层棚架 / 屋檐 / 露台，显示窗口保持 1280×720。共享镜头跟随双方并按高度差缩放，HUD 固定，头顶箭头标识玩家 / 电脑 / 木桩。
- 按住跳跃可落地连续跳，空中松开再按可二段跳，两次起跳使用相同初速，六位角色均可从地面跳到第一层或二段跳到第二层；下降时可停在平台，按住下穿过平台。闪移可穿人、躲攻击、打断短暂受击状态，最多储存 2 次，每 2.5 秒恢复一次，使用第二次不会重置已有恢复计时。
- 轻击、重踢、绊倒、浮空、冰冻与倒地有不同表现；抱摔经过抓取、越肩抛掷、另一侧落地和起身。倒地恢复带保护，避免一直被压在角落。
- 伤害整体缩至此前 44%，长连段衰减更强；九组固定随机种子的主动 AI 对战首局约 30.1–50.5 秒，中位数 41.5 秒，实际玩家时长随操作而变。
- 动态光效：挥拳拖光、踢腿弧光、命中星芒、冲击环、技能尾焰、地面震波、蓄力光晕及必杀闪光。
- 声音：打击、格挡、起跳、落地、技能、必杀及原创街机背景乐；大笑使用随项目保存的**网络经典录音**，没有用合成笑声替代。
- 手机虚拟摇杆：拖动移动、推满奔跑、同向连拨冲刺、上推跳跃、下拉蹲下；六个攻击按钮与防御键支持多指操作，方向 + 必杀可以选择组合大招。横屏使用紧凑擂台布局。
- 暂停与全屏位于顶部“对手脾气”左侧，全屏时保留紧凑工具栏；游戏画面内没有大笑按钮，角色文字标识背景透明。手机暂停面板适应游戏画面，暂停时隐藏触屏操作；另有失焦自动暂停、音量 / 背景乐 / 震屏 / 触屏设置和本地人机战绩。

## 操作

| 动作 | P1 | P2 |
| --- | --- | --- |
| 左 / 右 | A / D | ← / → |
| 跳跃 / 下蹲 | W / S | ↑ / ↓ |
| 连跳 / 二段跳 | 按住 W / 空中再按 W | 按住 ↑ / 空中再按 ↑ |
| 闪移 | E，配方向 | 8 / 小键盘 8 / 斜杠，配方向 |
| 平台下落 | 按住 S 约 0.2 秒 | 按住 ↓ 约 0.2 秒 |
| 直拳 / 踢腿 | J / K | 1 / 2 |
| 专属技能 / 满格必杀 | L / I | 3 / 4 |
| 升龙 / 抱摔 | U / O | 6 / 7 |
| 冲刺 / 奔跑 | 双击方向，继续按住；左 Shift + 方向 | 双击方向，继续按住 |
| 防御 | 空格，或后退 | 右 Shift，或后退 |
| 捧腹大笑 | H | 5，或 B |
| 暂停 / 继续 | Esc / P | Esc / P |

P2 兼容数字小键盘，也支持 `N / M / , / .` 对应拳 / 脚 / 技 / 必杀。标准手柄用摇杆 / 方向键移动，上推跳跃，A/B/X/Y 出招，肩键防御，左右扳机为升龙 / 抱摔，按下左摇杆闪移。手机摇杆持续上推会落地连跳，松开再上推触发二段跳；右侧“闪”显示剩余次数，用尽后显示恢复倒计时。

iPhone 的任意网页元素原生全屏支持受限，因此全屏按钮优先尝试标准 / WebKit API，缺失或拒绝时改用可见窗口内的沉浸模式，支持安全区域、地址栏高度变化和退出后恢复页面位置。网页无法强制隐藏浏览器地址栏。实现与测试范围见 [兼容性说明](docs/COMPATIBILITY.md)。

| 出招 | 效果 |
| --- | --- |
| J → J → J | 命中后衔接三连奶拳 |
| J → K → L → I | 连续命中后接六段终式；本连招已花的技能奶气计入 100 总额（最多抵扣 35） |
| 下 + J / K | 蹲拳 / 扫堂腿 |
| 跳跃 + J / K / L | 空中拳 / 飞燕踢 / 空中散气 |
| K + L | 两段旋风腿，消耗 20 奶气 |
| 冲刺中 J / K | 冲肩拳 / 滑铲 |
| 下 + L / 前 + L | 伏地奶气震 / 破风掌，消耗 20 / 30 奶气 |
| ↓ → 前 → L | 半秒内完成，螺旋奶气波，消耗 35 奶气 |
| I | 角色专属必杀 |
| 前 + I 或 K + I | 五段百裂奶拳 |
| 下 + I 或 U + I | 三段九天升龙 |
| 后 + I 或 L + I | 四波天降奶雨 |

“前 / 后”相对角色朝向。专属技能消耗 25 奶气，独立必杀消耗 100。命中、防御、受击与时间推进积攒奶气。下蹲可避开高拳、高踢、高段气功；跳跃躲扫腿和震地。飞踢、空袭可以打蹲下的对手，升龙可以对空。低段需要蹲防，空中压制需要站防，抱摔能破防。防御承受少量削血。

## GitHub Pages 部署

### 使用自带 GitHub Actions（推荐）

1. 将此项目的源文件提交到 GitHub 仓库的 `main` 或 `master` 分支，包括 `.github/workflows/pages.yml` 与 `assets/`。
2. 打开仓库 **Settings → Pages → Build and deployment → Source**，选择 **GitHub Actions**。
3. 推送代码或手动运行 **Test and deploy the arcade**。流程会执行战斗测试、生成 `dist/`，然后发布。
4. 在部署任务的 `github-pages` 环境中打开站点链接。

配置依据：[GitHub 官方 Pages 发布说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。所有游戏资源使用相对路径，兼容 `https://用户名.github.io/仓库名/`。

### 手动上传静态成品

```sh
npm run build
```

把 `dist/` **里面的内容**上传到发布分支根目录，并在 Pages 中选择 **Deploy from a branch → 对应分支 → /(root)**。也可解压交付的 `releases/milkfrog-pages.zip` 后上传。无需安装构建依赖，也无需 API Key。

源文件、Pages 工作流和可部署静态包已经准备好。本轮修改未推送到远程仓库。

```sh
npm test
npm run build
```

58 项测试覆盖基础战斗、冲刺、两次闪移及 2.5 秒逐次恢复、连续跳与二段跳、六位角色在两张地图的实际平台可达性、角色缩放、宽地图与镜头、高低段判定、抱摔全过程、起身保护、角色效果、连招和多段必杀，以及固定种子的对战时长验证。
