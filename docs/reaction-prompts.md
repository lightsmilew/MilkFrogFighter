# 受击与起身动作

使用内置 imagegen，根据已在游戏中使用的 `art/source/milkfrog-walk.png` 保持经典奶蛙头身、绿眼与材质，生成透明 4×4、共 16 个受击 / 起身关键姿态。最终原图保存为 `art/source/milkfrog-reactions.png`。运行版本由 `scripts/prepare-assets.py` 裁切、按既有六套材质统一配色、压缩并合并到 `assets/fighters/{classic,green,red,purple,pink,blue}.webp`；没有额外 reaction 下载包。

16 个原图格按行优先：头部轻击三阶段、腹部受击三阶段、重击后仰三阶段、挑飞上升 / 下落两阶段、失衡滑倒、仰面倒地、撑地 / 单膝 / 起身三阶段。替换旧逻辑帧 8（闲置施法）、9（旧挑飞）、10（旧倒地），新增 13 个逻辑帧，每位角色由 35 帧变为 48 帧。`ANIMATION_FRAMES.reactions` 记录分组，倒地帧在滑倒末段与倒地状态共用，只在图集中存一份。旧攻击帧 4 保留给攻击，但受击不再使用。

`src/reactions.js` 按接触类型和受击年龄选择连续姿态，升空按垂直速度区分上升 / 下落；控制定身与真实冻结使用对应姿态。单次霜印不再伪装成完全冻结。非投掷反应由 `reactionMotion()` 补充有上限的位移、倾斜和体积变化。倒地结束后才推进起身计时，三个起身姿态完整可见。
