# 移动与角色调参

运行参数集中在 `src/config.js`。修改后刷新本地预览，发布前重新运行 `npm test` 和 `npm run build`。

| 参数 | 当前值 | 作用 |
| --- | --- | --- |
| `WORLD.fighterScale` | 0.7 | 战斗图像、攻击与受击几何、投射物、光效的缩放比例 |
| `WORLD.spriteSize` | 175 | 战斗图像基础绘制尺寸，选蛙卡片使用独立展示尺寸 |
| `WORLD.standHeight` / `crouchHeight` | 145.6 / 91 | 站立与下蹲身高，应与角色缩放同步 |
| `WORLD.pushDistance` | 75.6 | 两位站立角色互相挤开时的最小间距 |
| `WORLD.gravity` | 2050 | 重力；降低会让腾空时间更长 |
| `CHARACTERS[].speed` | 320–430 | 各角色普通移动速度，单位为世界单位 / 秒 |
| `CHARACTERS[].jump` | 1160–1280 | 起跳初速；增大可跳得更高 |
| `MOVEMENT.runMultiplier` | 2.15 | 奔跑倍率，例如奶蛙 360 × 2.15 = 774 |
| `MOVEMENT.dashForward` / `dashBack` | 1180 / 1020 | 双击方向的前冲 / 后冲速度 |
| `MOVEMENT.dashDuration` | 0.20 秒 | 冲刺持续时间，继续按方向可接奔跑 |
| `MOVEMENT.airJumpRatio` | 1 | 二段跳初速相对角色起跳初速的比例 |
| `MOVEMENT.blinkSpeed` / `blinkDuration` | 2300 / 0.16 秒 | 闪移速度与持续时间，基础位移约 368 |
| `MOVEMENT.blinkCharges` | 2 | 最大储存次数 |
| `MOVEMENT.blinkRecharge` | 3 秒 | 每恢复一次所需时间，逐次恢复 |

闪移举例：满次数时先用一次，0.2 秒后再用一次，第二次不重置恢复计时；从首次消耗起约 3 秒恢复第一次，约 6 秒恢复第二次。暂停期间计时停止。短时间连续按两次会缓存第二次，在第一段位移结束后接上。

本轮将奶蛙普通速度从 310 提至 360、奔跑倍率从 1.6 提至 2.15，奔跑由 496 提至 774；前冲从 850 提至 1180。跳跃初速从 1030 提至 1220，重力从 2150 调至 2050，一段跳最高约 353 世界单位；二段跳从 84% 初速改为完整初速。两张地图的六位角色均验证一段跳上第一层，以及较早 / 较晚二段跳上第二层。

六位角色的普攻、技能与必杀参数位于 `src/styles.js` 的 `STYLES[].overrides`；AI 的反应、连招执行、防御与脱身概率位于 `src/config.js` 的 `DIFFICULTIES`。修改启动、有效、收招、范围与费用时，应同时检查流派连招是否仍能连续命中。

满血通过 `WORLD.maxHealth` 设置，目前为 1000。招式原始伤害沿用百分制平衡单位，结算时统一乘以 `maxHealth / 100`，回血、三层绯印追加伤害也同倍率换算，奶气仍为 100 上限。例：基础直拳实际伤害为 `7 × 0.44 × 10 = 30.8`，奶粉普通返程弹按攻击编号一次回复 20。AI 的低血判断和血条颜色使用满血比例。高度上限 `WORLD.top=-1500`，背景边界独立由 `STAGES.imageTop / imageBottom` 控制，避免改背景时挪动平台。
