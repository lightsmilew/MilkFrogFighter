# 六流派战斗设计

输入沿用拳 J、脚 K、技能 L、必杀 I、升龙上 + J、抱摔下 + J，手机沿用现有按钮与摇杆。`styles.js` 将 28 个通用招式槽解析为每个角色的招式、动作和机制。共用输入便于换角色，流派差异通过攻击节奏、位移、投射物与状态判定实现。

| 角色 | 流派与核心机制 | 推荐命中路线 |
| --- | --- | --- |
| 奶蛙 | 螺旋流：聚拢掌、突掌和螺旋丸；后 L 反击架势逆转一击，能反射远程弹，仍会被抱摔破解 | J → J → K → 前 L → I |
| 奶绿 | 风影流：快拳、穿身风刃、独立延迟分身；风轮与分身空袭覆盖不同高度 | J → J → K → 前 L → 前 I |
| 奶红 | 熔火流：慢启动重击、一次轻击霸体、延迟三重火柱、火山喷发 | J → J → K → 前 L → I |
| 奶紫 | 幻月流：远端月刃、牵引结界、追踪珠；前 L 幻步换边后反向攻击 | J → K → J → L → 后 I |
| 奶粉 | 绯绫流：长距离丝带、回旋心弹；普通攻击叠三层绯印绽放回血，返程弹可第二次命中 | J → K → J → L → I |
| 奶蓝 | 冰镜流：冰针扇阵、分段冰棱、三层霜印冻结；后 L 冰镜拦截飞行物，承受足够攻击会碎裂 | J → J → K → L → 下 I |

J J J 是各自的三段普攻。J K 接分支，K J 接回身追击，J J K 接流派终结技；必须确认命中才能取消收招。方向技能分别为前 L 突进、下 L 控场、后 L 战术、下→前 L 强化技；I、前 I、下 I、后 I 选择不同奥义。完整名称可在页面招式本展开查看。

J / K / L / I 每次按下只出一招，长按不续发；三段拳与其他连招需再次按键，技能和必杀仍支付正常奶气。按住方向后再按攻击可直接使用对应方向招式。J 未松开时再按 K 会接脚法分支；输入缓存可等到命中确认后再解析。普通空中攻击保留移动，按住跳跃时可加入或反转左右方向。P1 / P2 防御键为 Q / Enter，后退自动防御继续保留。

受击时按下攻击可预输入，合法硬直结束后执行一次，不在受击过程中反复出招。普通缓存为 0.30 秒，受控期间暂存，总寿命最多 2 秒。连续地面硬直达到 1.1 秒会结束并给予短暂保护，恢复时预输入的轻攻击也有短暂起手保护；正常命中取消和完整的多段招式仍保留。头部、腹部、重击后仰、挑飞、滑倒和起身使用专门绘制的动作，实际冻结和束缚有对应固定 / 挣扎姿态。

大招有气量要求，取消窗口也受招式等级限制。连携中付费技能最多抵扣 35 奶气，长连击伤害逐次衰减；持续格挡可以挡住多段攻击，不会因格挡硬直而自动漏掉后续段。分身可以格挡，火柱、结界和冰棱有范围及预警，可以移动或跳跃避开；冰镜有耐久。闪移最多存两次，每 3 秒逐次恢复一次。

AI 根据当前可见攻击、距离、高度、命中确认和资源选择行动，具有近身压制、收招反击、对空、投技、追平台、格挡、闪移及部分战术拦截。各难度调整反应间隔和行动执行概率，使用和玩家相同的受击、费用和库存规则。固定乱按脚本的 18 个种子对局中，简单 / 普通 / 困难分别获胜 0 / 8 / 18 局，电脑最高连击分别为 7 / 7 / 12；这仅是压力回归，不代表真人胜率。

动作新增素材是六位角色各四个姿态，保留二十个移动、腾空、防守、受击等基础姿态。新旧肤色、高光与阴影在离线打包时统一。不同招式再使用启动、有效和恢复阶段的姿态切换、重心与旋转补充连贯性。

## 独立控场与追击奥义

持续技能改为短施法后留下独立战斗对象。风阵、牵引结界、绯绫场的控制分别为 0.62 / 0.86 / 0.78 秒，施法约 0.38–0.39 秒；月蚀与冰笼的控制约 1 秒，施法 0.48 秒。控制中的对手有独立倒计时与封印表现，施法者能先恢复并接近。同一次施法不刷新控制，脱控后有 0.8 秒抗控制；消耗闪移可解除控制，格挡成功也不附加状态。

后 + I 的螺旋、风影、幻月采用四次独立预警落阵，预警发出后锁定位置，后续波次重新预判移动。每次施法约 0.52 秒，场地效果继续存在。下列三位使用不同机制：

| 角色 / 奥义 | 路径与命中效果 | 画面与应对 |
| --- | --- | --- |
| 奶红 · 熔火追爆 | 三次追爆留下地面余火，末次扩大爆炸并炸飞；不附加定身 | 橙红实体焰团、膨胀爆环、低矮余火；走出爆点、闪移或跳离余火 |
| 奶粉 · 绯绫回环 | 两枚心核丝带追踪空地目标，命中后提早折返；去返分别命中，首次可定身，一次施法的命中回血只结算一次 | 两条可见曲线、心核与旋转丝带；利用返程路径走位，也可格挡或闪移 |
| 奶蓝 · 冰镜折射 | 在目标两侧立两块可破坏冰镜，四枚冰刺交叉夹击，随后中心冰花冻结 | 蓝色晶面、斜向冰刺、六角冰花；预警后移出中心，冰镜可拦截对方投射物 |

跳跃 + I 新增独立空中奥义，向对手预测位置发出扇形压制并触发延迟爆发；奶粉使用追踪回旋双绫，奶红 / 奶粉 / 奶蓝的爆发分别为火爆 / 花瓣 / 冰花。上 + I 可从地面直接起跳施放；已有前、下、后方向奥义优先级保留。所有投射物仍用真实碰撞、闪移无敌、格挡、伤害衰减及正常奶气费用，不直接扣除远处目标血量。

行走为八帧，快速移动改用六帧专属跑步，前倾、摆臂、跨步与腾空动作均来自新图。两种步态按实际位移推进，后退反向播放，顶墙停止推进，切换时接续相位。新图脚底与头身基准离线对齐，沿用六套肤色；均与战斗动作合入每位角色唯一的 35 帧图集，替换三张旧移动姿态，不重复保留独立 walk 包。制作记录见 [walk-prompts.md](walk-prompts.md)、[run-prompts.md](run-prompts.md)。

连续拳使用专属轻击、基础伸拳和专属重击三个不同姿态，按启动、打击、随动与恢复回架编排；旋风腿和飞踢恢复各自专用动作。无真实挑飞的技能命中后不会转圈，冻结、定身、击退、挑飞、绊倒、抱摔和起身分别处理。现有图集即可完成这些衔接，本轮未增加图片资源。

流派在角色名旁显示深底、高对比描边徽签，手机同样可见。闪移在双方资源条下方显示两格独立恢复条：可用格点亮，下一格按 3 秒逐次填充，格内显示剩余秒数；第二格排队恢复时显示完整等待时间。手机闪移按钮同步显示次数、下一次恢复秒数与两格小进度。

技能功能参考了《火影忍者》游戏官方介绍中的分身协同、拘束接奥义、快速位移及近战回复思路，角色、名称、图像与声音沿用奶蛙主题。参考：[官方开发说明第十期](https://naruto-official.com/news/01_2400?existence=1&nolangsuggestion=1)、[官方 STORM CONNECTIONS 战斗调整记录](https://en.bandainamcoent.eu/naruto/news/naruto-x-boruto-ultimate-ninja-storm-connections-patch-140-notes)。

## 难度与闪移修正

原算法在每个模拟步重新尝试同一命中取消，实际接招概率接近必成，抹平难度差异；闪移又排在多个提前返回之后，且每次受击都会重置 0.1 秒脱身窗口，快速连段中很难满足条件。现在每次确认只判断一次，闪移独立于普通思考计时执行，按连续受击累计脱身窗口。所有角色仍遵守两次储存、每 3 秒逐次恢复的资源规则。

| 难度 | 普通思考间隔 | 计划接招上限 | 收招后的空隙 | 闪移倾向 |
| --- | --- | --- | --- | --- |
| 轻松 | 约 380 ms | 两段后停止主动衔接 | 620 ms | 较少，受压后较慢判断 |
| 普通 | 约 210 ms | 四段后留空隙 | 140 ms | 连段脱身、避开场地技能 |
| 挑战 | 约 100 ms | 最多七段主动衔接 | 55 ms | 更快脱身、躲弹与主动接近 |

上限控制下一招的规划，单个多段技能可以贡献多次命中。固定压力脚本中三档电脑每局平均闪移约 2.3 / 5.4 / 5.1 次，困难局结束较快。运行 `node scripts/benchmark-ai.mjs` 可重现胜局、连击与闪移统计。普通难度降低连续压制，保留反击和防守。

上 + 拳优先选择升龙，地面方向输入保留 80 ms 合招窗口，起跳躲避从输入开始生效；空中二段跳仍有独立边沿。下 + 拳改为抱摔，后 + 拳保留蹲掌。平台上抱摔会优先于下穿操作。键盘、手机摇杆和手柄使用相同判定；U/O 和 P2 的 6/7 仅为兼容入口。


## 奶蛙与奶绿空中 / 远程奥义重做

- 奶蛙「大玉·坠击」：一枚沿弧线飞行的大玉，前半程调整落点，接触或到达后原地爆发；没有只装饰而不造成接触的串珠。后 + 必杀「螺旋回流」为四次锁定身体高度的圆形收拢爆发，后续波次在施法者收招后继续，预警后可闪移躲开。
- 奶绿「风影·双袭」：两侧分身斜向俯冲，随后交叉风刃在预警位置切开；后 + 必杀「影分身·交叉突袭」为三轮双侧穿身分身和一次交叉收尾。分身使用现有拳 / 踢图帧，风刃与移动接触位置一致。
- 两套均去掉通用的纵向螺旋光柱。圆形场按实际圆判定，移动弹 / 分身按经过的线段扫掠受击框，不依赖画面帧率恰好落在目标上。
