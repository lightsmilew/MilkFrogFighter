# 六流派战斗设计

输入沿用拳 J、脚 K、技能 L、必杀 I、升龙 U、抱摔 O，手机沿用现有按钮与摇杆。`styles.js` 将 27 个通用招式槽解析为每个角色的招式、动作和机制。共用输入便于换角色，流派差异通过攻击节奏、位移、投射物与状态判定实现。

| 角色 | 流派与核心机制 | 推荐命中路线 |
| --- | --- | --- |
| 奶蛙 | 螺旋流：聚拢掌、突掌和螺旋丸；后 L 反击架势逆转一击，能反射远程弹，仍会被抱摔破解 | J → J → K → 前 L → I |
| 奶绿 | 风影流：快拳、穿身风刃、独立延迟分身；风轮与分身空袭覆盖不同高度 | J → J → K → 前 L → 前 I |
| 奶红 | 熔火流：慢启动重击、一次轻击霸体、延迟三重火柱、火山喷发 | 下 J → K → 前 L → I |
| 奶紫 | 幻月流：远端月刃、牵引结界、追踪珠；前 L 幻步换边后反向攻击 | J → K → J → L → 后 I |
| 奶粉 | 绯绫流：长距离丝带、回旋心弹；普通攻击叠三层绯印绽放回血，返程弹可第二次命中 | J → K → J → L → I |
| 奶蓝 | 冰镜流：冰针扇阵、分段冰棱、三层霜印冻结；后 L 冰镜拦截飞行物，承受足够攻击会碎裂 | J → J → K → L → 下 I |

J J J 是各自的三段普攻。J K 接分支，K J 接回身追击，J J K 接流派终结技；必须确认命中才能取消收招。方向技能分别为前 L 突进、下 L 控场、后 L 战术、下→前 L 强化技；I、前 I、下 I、后 I 选择不同奥义。完整名称可在页面招式本展开查看。

大招有气量要求，取消窗口也受招式等级限制。连携中付费技能最多抵扣 35 奶气，长连击伤害逐次衰减；持续格挡可以挡住多段攻击，不会因格挡硬直而自动漏掉后续段。分身可以格挡，火柱、结界和冰棱有范围及预警，可以移动或跳跃避开；冰镜有耐久。闪移最多存两次，每 3 秒逐次恢复一次。

AI 根据当前可见攻击、距离、高度、命中确认和资源选择行动，具有近身压制、收招反击、对空、投技、追平台、格挡、闪移及部分战术拦截。各难度调整反应间隔和行动执行概率，使用和玩家相同的受击、费用和库存规则。固定乱按脚本的 18 个种子对局中，简单 / 普通 / 困难分别获胜 8 / 17 / 17 局，电脑最高连击分别为 11 / 15 / 32；这仅是压力回归，不代表真人胜率。

动作新增素材是六位角色各四个姿态，保留二十个移动、腾空、防守、受击等基础姿态。新旧肤色、高光与阴影在离线打包时统一。不同招式再使用启动、有效和恢复阶段的姿态切换、重心与旋转补充连贯性。

技能功能参考了《火影忍者》游戏官方介绍中的分身协同、拘束接奥义、快速位移及近战回复思路，角色、名称、图像与声音沿用奶蛙主题。参考：[官方开发说明第十期](https://naruto-official.com/news/01_2400?existence=1&nolangsuggestion=1)、[官方 STORM CONNECTIONS 战斗调整记录](https://en.bandainamcoent.eu/naruto/news/naruto-x-boruto-ultimate-ninja-storm-connections-patch-140-notes)。
