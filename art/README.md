# 美术制作原图

`source/` 保存仍被离线处理脚本使用的九张 PNG：基础动作、补充动作、六流派动作、八帧行走、六帧跑步、十六帧受击 / 起身、主页街景，以及晴 / 雨两张高场景。

重新处理角色运行 `scripts/prepare-assets.py`，只处理高场景运行 `scripts/prepare-stages.py`。两者需要 Pillow（角色处理还需要 NumPy）；普通构建直接使用 `assets/` 的成品，不依赖 Python。

这里的原图不进入 `dist/`，页面也不请求它们。旧的两张矮场景原图及五份废弃 WebP 已删除，运行素材清单由 `scripts/build.mjs` 检查。

移动、攻击、受击与起身现在合并到每个角色的一张 48 帧矩形图集中，旧两张行走、一张疾跑，以及三个闲置 / 旧受击姿态被替换。生成脚本不会再输出独立 walk / run / reaction 包，并会清理这十二个已知过时文件名（若存在）；制作 PNG 作为离线输入保留。
