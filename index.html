P1：W + J 升龙、S + J 抱摔、E 闪移；P2：↑ + 1 升龙、↓ + 1 抱摔、8（或 /）闪移。双击方向冲刺，继续按住奔跑，P1 也可左 Shift 加速。按住 W / ↑ 落地后连续跳，空中松开再按可以二段跳；平台按住 S / ↓ 可穿过下落。H 大笑（P2 按 5 或 B）。手柄 A/B/X/Y 出招，肩键防御，上 / 下 + 拳为升龙 / 抱摔，按下左摇杆闪移。

手机：右手只保留拳、脚、技、必杀、闪、挡六键，摇杆上 + 拳升龙、下 + 拳抱摔。摇杆推满奔跑，同向连拨冲刺；持续上推会落地连跳，松开再上推可二段跳，平台下拉可跳下。右手“闪”可存两次、每 3 秒恢复一次，可穿过对手，也能在短暂受击后脱身。方向与攻击可同时按，前 / 下 / 后 + 必杀选择突进 / 升空 / 空袭奥义。前后相对角色朝向；P2 的 1/2/3/4 对应 J/K/L/I，上 / 下 + 拳与 P1 相同。

连招与组合大招

    街坊传授的三件事

    1. 命中，再接招。拳命中后接脚，脚命中后接技能，技能命中后能接必杀。三次连续命中后按中立必杀，会接该流派的连携终式。
    2. 高低段要看清。下蹲避开直拳、高踢与高段气功；跳跃躲扫腿和震地。飞踢、空袭能压蹲下，升龙能打空中。低段要蹲防，空中压制要站防；抱摔可破防。
    3. 练习场随便试。无限时间、无限奶气，木桩脱离连击后回满体力。点击底栏可切换木桩格挡。

    Esc / P 暂停。切换窗口会自动暂停。双人请使用键盘或两只手柄；单个触屏面板控制 P1。
